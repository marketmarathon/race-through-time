**How the figures were made.** Before 2009 there is no single consistent measure of browser use, so each period uses the
best available source, and the race joins them. Everything before January 2009 is an estimate and is shown with stripes,
with the source named on screen. The sources measured different things (a survey of web users, the visitors to one
university web server, visitors to the websites a tracking company served), so the numbers can jump where one source
hands over to the next.

**Data**
- 1994: GVU's WWW User Surveys, Georgia Tech. Copyright Georgia Tech Research Corporation (GTRC); used with
  acknowledgement of GTRC, as its terms ask.
- 1996–2000: University of Illinois EWS web server, monthly browser reports (archived copies on the Internet Archive).
- 2001–2002: WebSideStory StatMarket press releases. 2002–2007: OneStat.com press releases (archived copies).
- 2007–2008: W3Counter monthly reports (archived copies).
- 2009–2026: StatCounter Global Stats, browser market share, worldwide, all platforms, licensed under CC BY-SA 3.0:
  https://gs.statcounter.com/browser-market-share
- The dataset built for this video (and how it was built) is public: https://github.com/marketmarathon/race-through-time
